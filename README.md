# تطبيق تذكير | Notify PWA 🕌 🎯

تطبيق ويب تقدمي (PWA) فائق السرعة وخفيف مبني بأحدث تقنيات **Astro 5** و **Cloudflare D1 Database** و **Cloudflare Workers**.
مصمم خصيصاً لمتابعة الصلوات ومحاربة التشتت اليومي عبر أجهزة الحاسوب، اللابتوب، الموبايل والتابلت، مع ميزة الإشعارات التفاعلية ذات أزرار الرد المباشرة (Actionable Push Notifications).

---

## 🌟 المميزات الرئيسية

### 1. إشعارات تفاعلية مع أزرار رد مباشر (Actionable Notifications)
- عند وصول إشعار الصلاة، يظهر مباشرة على شاشتك زران:
  - `صليت ✅`: لتسجيل أداء الصلاة فوراً وإيقاف التنبيهات لباقي اليوم.
  - `لسة (ذكرني بعد ربع ساعة) ⏰`: لتأجيل التنبيه وإعادة تذكيرك بعد 15 دقيقة تلقائياً.
- عند الضغط على أي زر، يقوم الـ **Service Worker** في الخلفية بإرسال ردك إلى خوادم Cloudflare لتسجيل حالتك دون الحاجة لفتح المتصفح إطلاقاً!

### 2. متابعة الصلاة بالحساب الفلكي الدقيق
- حساب فلكي دقيق باستخدام مكتبة `adhan` الموثوقة.
- قائمة دول ومدن جاهزة (مصر، السعودية، الإمارات، الكويت، قطر، الأردن، فلسطين، المغرب، الجزائر، وغيرها).
- تنبيه مسبق قبل الأذان للاستعداد والوضوء (مع إمكانية ضبط الدقائق من الإعدادات).
- متابعة بعد الأذان للتأكد من أداء الفريضة.
- شاشة متابعة حية لصلوات اليوم مع عداد تنازلي لموعد الصلاة القادمة.

### 3. فترات اليوم وبنك الرسائل العشوائية (محاربة التشتت)
- قسّم يومك لفترات (مثل: فترة العمل الصباحية، فترة الراحة والمساء).
- أضف بنك رسائل وأهداف وتذكيرات لكل فترة.
- **نمط الإرسال العشوائي**: يختار النظام وقتاً مفاجئاً وغير متوقع داخل الفترة ويرسل لك رسالة تكسر السرحان وتذكرك بهدفك الحالي أو شرب الماء أو الذكر.
- يدعم أيضاً التكرار الدوري أو موعداً ثابتاً يومياً.

### 4. نظام حسابات ومستخدمين مستقل (Multi-user)
- تسجيل دخول وإنشاء حساب (`/login` & `/register`).
- عزل كامل لبيانات كل مستخدم (أجهزته، أوقات صلواته، رسائله وإعداداته).
- أمان كامل بفضل تشفير PBKDF2 عبر Web Crypto API.

### 5. تطبيق ويب تقدمي (PWA)
- تثبيت بنقرة واحدة (Add to Home Screen / Install App) على Chrome, Edge, Safari (iOS 16.4+), Android.
- يعمل بدون اتصال بالإنترنت لواجهة التطبيق الأساسية (Offline App Shell).

## 🚀 التشغيل المحلي (Local Development)

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. إنشاء جداول قاعدة البيانات المحلية (Cloudflare D1)
npx wrangler d1 execute notify_db --local --file=./schema.sql

# 3. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:4321`

---

## ☁️ النشر على Cloudflare (Deployment)

1. **إنشاء قاعدة بيانات D1 سحابية على Cloudflare**:
   ```bash
   npx wrangler d1 create notify_db
   ```
2. **وضع الـ database_id الناتج في ملف `wrangler.json`**.
3. **تنفيذ الـ Schema على السحابة**:
   ```bash
   npx wrangler d1 execute notify_db --remote --file=./schema.sql
   ```
4. **النشر بنقرة واحدة**:
   ```bash
   npm run build
   npx wrangler pages deploy dist
   ```

## ⚙️ جدولة الإشعارات التلقائية (Cloudflare Cron Triggers)
يقوم محرك الجدولة بفحص مواقيت الصلوات والرسائل المجدولة كل دقيقة عبر نقطة النهاية:
`GET /api/cron/tick`
يمكنك ربطها بـ Cloudflare Cron Triggers في الـ Worker أو أي خدمة Cron مجانية مثل Cron-Job.org.
